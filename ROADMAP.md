# WoodRig V1

El objetivo de estas ocho fases es dejar lista la web de presentación y el flujo de demostración para validar la gama y la experiencia de compra.

| Fase | Entrega | Referencia |
| --- | --- | --- |
| 1. Marca y base web | Home responsive, identidad visual, navegación y arquitectura Vue | `2d01cac`, `18c8a9c` |
| 2. Catálogo | Familias, búsqueda, fichas, imágenes conceptuales y productos relacionados | `18c8a9c` |
| 3. Ayuda y accesibilidad | Guía de compatibilidad, FAQ, páginas legales de ejemplo y foco al cambiar de página | `18c8a9c`, `28b037e` |
| 4. Configurador | Enlace que reproduce el modelo y los componentes seleccionados | `c19cf47` |
| 5. Compra de prueba | Carrito, confirmación e historial que resisten la recarga de la pestaña | `fe08aaa` |
| 6. Metadatos | Títulos y descripciones por ruta, imagen por ficha y directiva de robots para el flujo de prueba | `658f19f` |
| 7. Integración continua | Instalación limpia, lint, tipos y build en GitHub Actions | `b6f4482` |
| 8. Cierre de la V1 | Verificación sobre el build de producción y criterios de aceptación documentados en el README | Commit de cierre |

## Lanzamiento comercial

Quedan pendientes las fichas técnicas validadas, las fotografías y los recursos definitivos de montaje y plegado, los datos del titular, las condiciones de compra y las integraciones de inventario, cuentas, pedidos, pagos, facturación y envíos.
